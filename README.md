# Telegram AI Chatbot 🤖

Claude AI powered Telegram bot with Amharic support.

## Features

✅ Claude 3.5 Sonnet AI
✅ Conversation memory
✅ Amharic language support
✅ Fun commands (/joke, /quote)
✅ Error handling
✅ 24/7 running on Railway

## Commands

- `/start` - Start bot
- `/help` - Show help
- `/joke` - Tell a joke
- `/quote` - Random quote
- `/clear` - Clear conversation history
